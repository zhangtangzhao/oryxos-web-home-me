# 科技日报方法论

1. **选题**：从信息源（MCP tech-news 工具返回的条目）中挑选三条跨领域要闻：
   AI / 芯片 / 云计算 / 开源 / 硬件，避免三条同源。
2. **摘要**：每条 80 字以内，注明来源与时间；不确定的消息标注「待证实」。
3. **点评**：结合用户关注方向（用 recall_memory 查询「关注」获取）写一段
   150 字深度点评，说明对本领域的影响。
4. **排版**：`## 今日要闻`（三条列表）+ `## 深度点评`（一段）+ 末行日期。
